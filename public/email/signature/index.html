Cum o pui în programul de mail

„Copiază semnătura” pentru Gmail și Outlook; „Copiază pentru Apple Mail” pentru Mail pe Mac (imaginile vin în semnătură); „Copiază codul HTML” pentru programele cu editor HTML.

  1. Apple Mail (Mac): Apasă „Copiază pentru Apple Mail” → Mail → Configurări → Semnături → alege contul → + → lipește (⌘V) în câmpul din dreapta. Debifează opțiunea de sub el care potrivește mereu fontul implicit al mesajului (Always match my default message font), altfel Mail schimbă fontul. Câmpul e îngust, așa că semnătura pare tăiată în dreapta; în mesaj apare întreagă.
  2. Gmail: ⚙ → Vezi toate setările → General → Semnătură → Creează → lipește → „Salvează modificările”, jos de tot.
  3. Outlook (nou, web, Mac): Setări → Conturi → Semnături → Semnătură nouă → lipește → Salvează. Alege-o apoi ca implicită pentru mesajele noi și pentru răspunsuri.
  4. Outlook clasic (Windows): Fișier → Opțiuni → E-mail → Semnături → Nou → lipește → OK.
  5. Thunderbird: Setări cont → Text semnătură → bifează „Utilizează HTML” → lipește codul HTML.
  6. Webmail (Roundcube și altele): Setări → Identități → Semnătură → treci editorul pe HTML / sursă (<>) → lipește codul HTML.
  7. iPhone (Mail): Deschide pagina asta în Safari pe iPhone (logistiq.ro/email/signature) → „Copiază semnătura” → Configurări → Apps → Mail → Semnătură → lipește. Dacă formatarea dispare, scutură telefonul și alege Anulează (Undo).
